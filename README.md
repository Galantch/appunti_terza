# 📚 appunti_terza

Repository di laboratorio per la **classe terza superiore – indirizzo Informatica**, a disposizione di tutti.

Raccoglie appunti e materiale di laboratorio relativi alle materie di indirizzo.

---

## 📁 Struttura della repository

```
appunti_terza/
├── informatica/
├── sistemi e reti/
├── tecn. informatiche/
└── telecomunicazioni/
```

| Cartella | Materia |
|---|---|
| `informatica/` | Informatica |
| `sistemi e reti/` | Sistemi e Reti |
| `tecn. informatiche/` | Tecnologie Informatiche |
| `telecomunicazioni/` | Telecomunicazioni |

---

## 🎯 Scopo

Mettere a disposizione di tutti gli appunti e il materiale di laboratorio della classe terza, organizzati per materia e facilmente consultabili.

## 🚀 Come consultare la repository

Puoi sfogliare le cartelle direttamente su GitHub oppure clonare la repository in locale:

```bash
git clone https://github.com/Galantch/appunti-terza
```

## 📝 Note

Il materiale ha scopo puramente didattico.
