# 📚 appunti_terza

Repository di laboratorio per la **classe terza superiore – indirizzo Informatica**.

Raccoglie appunti, esercizi, esercitazioni di laboratorio e progetti svolti durante l'anno scolastico nelle principali materie di indirizzo.

---

## 📁 Struttura della repository

```
appunti_terza/
├── informatica/
├── sistemi e reti/
├── tecn. informatiche/
└── telecomunicazioni/
```

### 💻 `informatica/`
Appunti ed esercizi di **Informatica**: programmazione, algoritmi, strutture dati, logica e sviluppo di piccoli programmi svolti in laboratorio.

### 🌐 `sistemi e reti/`
Materiale di **Sistemi e Reti**: architettura dei calcolatori, sistemi operativi, fondamenti di reti, modelli ISO/OSI e TCP/IP, indirizzamento e configurazioni svolte in laboratorio.

### 🛠️ `tecn. informatiche/`
Materiale di **Tecnologie Informatiche** (TPSIT): tecnologie e progettazione di sistemi informatici e di telecomunicazioni, esercitazioni pratiche e relazioni di laboratorio.

### 📡 `telecomunicazioni/`
Appunti ed esercizi di **Telecomunicazioni**: segnali, trasmissione dell'informazione, mezzi trasmissivi e relative esercitazioni.

---

## 🎯 Scopo

- Tenere ordinati gli appunti e i lavori di laboratorio dell'anno.
- Avere un archivio facilmente consultabile per studio e ripasso.
- Imparare a usare **Git** e **GitHub** per versionare il proprio lavoro.

## 🚀 Come usare la repository

Clona la repository sul tuo computer:

```bash
git clone https://github.com/<tuo-username>/appunti_terza.git
cd appunti_terza
```

Poi apri la cartella della materia che ti interessa e consulta i file al suo interno.

## ✍️ Convenzioni consigliate

- Un file (o una sottocartella) per ogni argomento o esercitazione.
- Nomi dei file chiari e senza caratteri speciali (es. `esercizio_01_cicli.py`).
- Commit frequenti con messaggi descrittivi (es. `Aggiunti appunti modello ISO/OSI`).

## 📝 Note

Il materiale ha scopo puramente didattico ed è in continuo aggiornamento durante l'anno scolastico.
